# サッカー審判道場

サッカー観戦をはじめたばかりの人が、**審判になって試合の場面を判定する**ことでルールを覚えるWEBアプリです。
中継でよく見る37の場面を、6つの「節」に分けて出題します。内容は **2026/27 サッカー競技規則**（IFAB・JFA）に基づいています。

公開URL：https://y-s-apps.github.io/shinpan-dojo/

## 遊び方

1. トップ画面で節（第1節〜第6節）を選ぶ
2. 「この節のポイント」を読んでキックオフ
3. ピッチの図と状況を見て、判定ボタンを押す
4. 正解・理由・観戦メモを読んで次の場面へ
5. 節の正解率に応じて★がつき、★の合計で審判ランク（見習い→4級→…→国際審判員）が上がる

判定した場面のルールは「審判手帳」に記録され、観戦中に見返せます。進み具合はブラウザに保存されます（端末やブラウザを変えると引き継がれません）。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色・文字・レイアウト） |
| `js/questions.js` | **問題データ**（節・場面・選択肢・解説） |
| `js/scene.js` | ピッチ図・電光ボードなどの描画 |
| `js/app.js` | 画面の切り替え、採点、ランク、保存 |
| `icons/` | アプリアイコンと、リンク共有時のプレビュー画像 |
| `tools/validate.js` | 問題データの書き間違いチェック |
| `tools/make_icons.py` | アイコンとプレビュー画像を作り直すスクリプト |

ビルドは不要です。ファイルを編集して `main` ブランチにプッシュすると、GitHub Pagesが自動で公開します（数分で反映）。

## 問題を追加・修正する

問題はすべて `js/questions.js` にあります。1つの場面はこの形です。

```js
{ id:'f2',                                   // 全体で重複しないID
  scene:{ v:'half', p:[...], ball:[x,y], arr:[...], lab:[...], oline:[...] },
  q:'問題文',
  c:['選択肢1','選択肢2'],                    // 2〜4個
  a:0,                                       // 正解の番号（0から数える）
  verdict:'判定（例：オフサイド）',
  why:'理由',
  watch:'観戦メモ（省略可）',
  card:{ t:'審判手帳の見出し', b:'審判手帳の本文' } }
```

### 図（scene）の種類

| v | 使いどころ | 主な項目 |
| --- | --- | --- |
| `half` | ピッチ上の場面 | 選手 `p`、ボール `ball`、矢印 `arr`、注記 `lab`、答えで出る線 `oline`・範囲 `zone` |
| `led` | 電光ボード（時間・交代・VAR） | `rows:[{t:'+4',c:'a'}]`（`c` は a=橙・g=緑・r=赤） |
| `cards` | カードの枚数 | `cards:[{c:'y',t:'前半'},{c:'q',t:'後半',rev:'r'}]` |
| `signal` | 主審のジェスチャー | なし |
| `zoom` | ボールとラインを真上から | `y`（ボールの位置）、`top`・`bottom`・`line`・`rev` の文字 |

### ピッチの座標（`half`）

縦向きのハーフピッチで、単位はメートルです。

- 横：`x` 0（左のタッチライン）〜 68（右のタッチライン）
- 縦：`y` 0（攻撃側のゴールライン）〜 52.5（ハーフウェーライン）
- ペナルティエリアは `y` 16.5 まで、ペナルティマークは (34, 11)

選手は `[チーム, 番号, x, y, 印]` で書きます。チームは `a`=青（攻撃）、`d`=白（守備）、`g`=白のGK、`r`=主審です。印は `'hl'`（強調）か `'down'`（倒れている）です。

矢印は `['pass'|'run'|'shot', x1, y1, x2, y2]`、注記は `[x, y, '文字', 'pre'|'rev']` です（`pre`=判定前だけ表示、`rev`=判定後だけ表示）。図は、選手・ボール・矢印・注記が入る範囲へ自動でズームします。

### 編集したら

```sh
node tools/validate.js   # 書き間違いのチェック
python3 -m http.server   # http://localhost:8000 で表示を確認
```

CSSやJSを変えたら、`index.html` の `?v=2` の数字を1つ上げてください（古いファイルがスマホに残るのを防ぎます）。

場面の数を変えたときは、`index.html` の `description` と、`tools/make_icons.py` のプレビュー画像の文言も合わせて直してください（トップ画面の数字は自動で変わります）。

## ルールの出典

- [IFAB Laws of the Game 2026/27](https://www.theifab.com/laws-of-the-game-documents/)
- [JFA サッカー競技規則](https://www.jfa.jp/laws/)
- [Jリーグ「2026/27 サッカー競技規則改正」の適用について](https://www.jleague.jp/news/article/34484/)

競技規則は毎年7月ごろに改正されます。改正があったら、関係する場面の解説を見直してください。
